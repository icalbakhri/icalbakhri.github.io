Membangun Nextcloud Super Cepat dengan FrankenPHP di Docker

Bagaimana saya meracik image Docker untuk Nextcloud yang lebih modern dan memiliki performa tinggi menggunakan server aplikasi FrankenPHP.

Nextcloud adalah salah satu solusi *self-hosted* terbaik untuk menyimpan data dan kolaborasi. Namun, konfigurasi standar menggunakan Apache atau PHP-FPM terkadang membutuhkan *tuning* ekstra untuk mendapatkan performa yang maksimal, terutama di lingkungan *container*.

Untuk menyelesaikan masalah tersebut, saya memutuskan untuk bereksperimen dan membangun Docker image Nextcloud kustom yang diotaki oleh FrankenPHP.

Apa itu FrankenPHP?

FrankenPHP adalah server aplikasi PHP modern yang ditulis menggunakan bahasa Go dan dibangun di atas web server Caddy. Ia menawarkan fitur luar biasa seperti:

  • Worker Mode: Melakukan *booting* aplikasi hanya sekali dan menyimpannya di memori, membuat *request* berikutnya ditangani jauh lebih cepat.
  • Caddy Engine: Otomatis mengurus sertifikat HTTPS, HTTP/3, dan kompresi tanpa konfigurasi rumit.
  • Single Binary: Tidak perlu repot menjalankan Nginx/Apache dan PHP-FPM secara terpisah di dalam Docker.

Proyek: nextcloud-frankenphp

Saya telah membuat *image* Docker yang menggabungkan basis instalasi Nextcloud terbaru dengan keandalan FrankenPHP. Repositori dan *registry* publiknya sudah tersedia untuk digunakan secara bebas oleh komunitas.

  • 📦 Docker Hub: icalbakhri/nextcloud-frankenphp
  • 💻 GitHub Repo: icalbakhri/nextcloud-frankenphp

Cara Penggunaan

Anda dapat dengan mudah mencoba *image* ini menggunakan Docker Compose. Berikut adalah contoh berkas docker-compose.yml yang sederhana: 

version: '3.8'

services:
  db:
    image: mariadb:10.6
    restart: always
    command: --transaction-isolation=READ-COMMITTED --binlog-format=ROW
    volumes:
      - db_data:/var/lib/mysql
    environment:
      - MYSQL_ROOT_PASSWORD=rahasia_root
      - MYSQL_PASSWORD=rahasia_db
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud

  app:
    image: icalbakhri/nextcloud-frankenphp:latest
    restart: always
    ports:
      - "8080:80"
    volumes:
      - nextcloud_data:/var/www/html
    environment:
      - MYSQL_PASSWORD=rahasia_db
      - MYSQL_DATABASE=nextcloud
      - MYSQL_USER=nextcloud
      - MYSQL_HOST=db

volumes:
  db_data:
  nextcloud_data:

Cukup jalankan perintah docker compose up -d, dan Nextcloud Anda akan berjalan menggunakan server FrankenPHP di port 8080.

Kesimpulan & Kontribusi

Menggunakan FrankenPHP untuk Nextcloud memberikan peningkatan responsivitas yang terasa pada UI dan proses sinkronisasi berkas. Jika Anda tertarik, silakan coba *image* ini di *homelab* atau server Anda.

Saya sangat terbuka untuk *Pull Request* atau *Issue* jika Anda menemukan bug atau memiliki ide peningkatan. Kunjungi repositori GitHub untuk berkontribusi!
